# pixel_v2 运行时美术包

状态：**已接入游戏运行时**  
接入日期：2026-10-23

本目录保存从项目素材库选定并接入 Godot 的 2D 粗颗粒马赛克素材。源 PNG 保持不变；不得未经用户确认重新生成、换色或覆盖素材。`scripts/pixel_terrain.gd` 直接绘制原始地表，`scripts/island_tiles.gd` 根据相邻格遮挡重复内沿。设施仍由 `AtlasTexture` 裁去画布留白。

## 内容

- `terrain/`：草地、农田、沙地、岩石、岩浆、金矿，以及用户选定的 `tree_tile_concept_v2_large.png` 大树原稿。
- `crops/`：水稻和番茄五阶段横向图集。
- `facilities/`：引擎室、储能室、抓钩工坊，以及 2026-10-26 确认并接入的水稻 / 番茄农务小屋。

农务小屋使用 `farm_management_hut_rice_v1.png`（金色屋顶）与 `farm_management_hut_tomato_v1.png`（红色屋顶）。两张图均保留生成原文件，由 `AtlasTexture` 按透明边界提取内容，不重绘、换色或改写源像素。按小屋管理作物选择建筑与面板图片；已有存档的小屋自动采用对应外观。农务小屋不再绘制储能室的烟囱、能源灯和临时文字牌。
- `characters/world_scale_reference_v1.png`：仅从中裁取 40 像素高的小人；树使用 `terrain/tree_tile_concept_v2_large.png`，不从比例表取替代版本。

## 连续地面与原稿提取

- 地块仍占 80×64 逻辑网格；顶面直接读取原始纹理，取消之前的小块截取、40×32 重新采样和镜像铺地。单块主体按等比缩放显示。
- 外侧保留原稿的像素齿边、高光与完整土石层，不再用程序画的直线边框替代。相邻格只在约 10 逻辑像素宽的共用边带，用原图纹理遮挡重复边沿；异材质边带采用阶梯形接合。共用外侧土石层也补齐接缝。
- 农田保留原稿的完整三行土垄和绿色田埂，不再把九块田的局部土壤放大拼成一张泥地。合并、搬移、裁剪时直接使用当前邻接关系；空洞不会被地表填平。
- 大树从 v2 原稿的 `(366, 13, 806, 742)` 区域提取，只去掉背景草地和半透明晕色，保留轮廓内部的原始 RGB；按原图宽高比绘制，高度为 110。
- 场景上的树、农作物与设施按地块前后顺序绘制。
- 作物图集并非等宽帧，运行时改用每株实际横向范围；同一作物的五阶段采用相同的等比缩放，避免切入邻株或拉宽植物。种植工具、悬停或选中时显示状态标记，普通飞行画面不堆叠进度条。

复核命令：`godot --path game --script res://tests/terrain_visual_test.gd`（仓库根目录）。测试校验 13 张源 PNG 的 SHA-256、原树 RGB 来源、作物阶段范围、原图直接引用和空洞，并在 0.55/1/1.4/2 倍缩放及非整数平移下检查接缝是否露底。预览输出到 `artifacts/game/original-art-island-preview.png`。素材校验基准位于 `tests/pixel_sources.sha256.json`，未经用户确认不得以更新基准的方式绕过素材修改检查。

## 运行时比例

- 小人：40 逻辑像素高；
- 成熟水稻：约 30 逻辑像素高；
- 成熟番茄：约 32 逻辑像素高；
- 大树：110 逻辑像素高；
- 单格地块：80×64 逻辑像素。

纹理过滤由 `project.godot` 的 `textures/canvas_textures/default_texture_filter=0` 关闭，保持最近邻硬边。原始概念与来源说明位于仓库根目录的 `asset-library/`。
