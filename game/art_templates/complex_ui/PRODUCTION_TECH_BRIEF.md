# 十级生产科技

- 范围：新增高效采集与作物增产，各十级；复用农林生产分类、既有图标和详情卡。十格进度收窄以适配原节点，不修改其他界面和素材。
- 效果（0–10级）：1、2、3、5、8、12、18、27、40、60、90 倍。地面采集叠加开拓 III 的两倍；飞船缩短采矿间隔、不扩大24份货舱或改变单矿资源；作物使用现有统一收获接口，产物和每份收获收益一起增长，种子返还仍1份。
- 费用（1–10级金币）：10、30、90、300、1000、3500、12000、45000、160000、600000。一级仅金币，二级起木石，四级起矿物，七级起岩浆晶。
- 保存：旧存档新增两项默认0级；新值只允许0–10整数。
- 验证：十级费用/收益递增、手工采集和作物/自动收获、飞船采矿间隔、旧存档及新等级往返、科技树节点显示和进度不溢出。
