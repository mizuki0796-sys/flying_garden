# 探险收集飞船概念 v1

- 用户要求：结合已确认工业港口风格，生成探险收集飞船，突出收集属性。
- 风格参考：`artifacts/game/harbor-directions-v3/harbor-four-directions-v3.png`；参考材质与色彩，不复制港口结构。
- 既有实现：`game/scripts/exploration_ship.gd::draw_ship` 为代码占位；现有采集物为石头、矿石与岩浆晶，容量 24。
- 允许变化：新飞船完整静态设计；船头收集铲斗及短导料槽，中央开放货舱及矿石，尾部小驾驶舱，左右静态升力风扇。机械结构仅用于表现用户授权的采集用途。
- 视觉重点：货舱占甲板约一半，少量大块矿物清楚可见；收集口到货舱形成可读的装载路径。
- 朝向：船头向上；港口外侧靠泊，非港口顶部停放。
- 规范：近正俯视纯 2D 正交、粗像素、有限色板、左上光源、每材质最多三档明度。蓝灰钢板、青绿钢梁、铜色连接件、少量黄黑警示条。
- 输出：一个独立透明背景 PNG 概念稿，非多方向精灵表。
- 保持：港口、已有飞船占位与所有游戏代码、玩法、动画、存档不变；不新增烟雾、灯光、粒子或运行状态。
- 验证：目视检查采集属性、矿物货舱及风格；逻辑像素、贴图尺寸、透明边缘和实际靠泊位置需接入时校准。
