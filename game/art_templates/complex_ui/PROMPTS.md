# 图像生成提示词模板

先读项目根目录 `COMPLEX_UI_ANIMATION_GUIDE.md`，再填空。需要独立位图时才调用图像生成；已有素材的旋转、摆动和透明度变化由动画实现。

## 提取可动部件

```text
编辑目标：[母版文件]。
仅提取：[部件]，用于[旋转/摆动/平移]。
保留：[轮廓、颜色、粗像素、投影、尺寸、光源]。
输出：单个部件、真正透明背景，孔洞也透明，无文字、无光晕。
画布：[尺寸]；部件位置：[坐标]；预期轴心：[坐标]。
移除所有不属于该部件的对象。不得重新设计其余建筑。
只补齐被遮挡而缺失的[指定区域]。不要新增机械件。
```

## 局部背衬补绘

```text
编辑目标：[母版文件]。
移除：[唯一可动部件]，补齐它背后必需的[墙体/面板]。
保持其余全部外观不变，包括[清单]。
沿用相同的方块像素、色板、视角、左上光源。
输出透明 PNG。该图仅用于[授权遮罩]内的背衬，不作为整图替代。
```

## 核验

提示词不能保证模型逐像素保真。生成后检查 alpha、轮廓、轴心和可见边界；不变区仍从原图绘制。保留实际使用的完整提示词、输出路径和 hash，区分生成结果与最终接入结果。
