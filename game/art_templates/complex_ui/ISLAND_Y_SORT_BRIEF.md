# 岛屿之间 Y 排序

- 用户要求：调整岛屿之间的 Y 排序，并截几张实际游戏图。
- 允许变化：主岛和可见外岛的整体前后绘制顺序；地块中心 Y 小的先画，Y 大的后画，同 Y 按固定索引排序。
- 锚点：外岛 `pos` 已为地块包围盒中心；主岛使用 `island_pos + island_bounds.get_center()`，兼容非对称扩建。
- 保持：全部原 PNG、岛内地块和建筑绘制、树木和作物动画、烟雾、地图、碰撞、存档、雷达及视野过滤。
- 不补绘、不拆素材；阴影、地面和岛内物件继续作为一座岛整体绘制。
- 验证：`game/tests/island_y_sort_test.gd` 检查上下交错、外岛互相排序、同 Y、非对称主岛、过滤和游戏数组索引不变；图形模式核对实际绘制调用顺序。
- 预览：同一脚本调用游戏 `_draw()`，固定时间 2.35、风力 0.14、1152×648；三场景缩放分别为 1.0 / 0.85 / 0.8，相机偏移见脚本，输出至 `artifacts/game/island-y-sort/`。第三场景分别覆盖普通和缓存渲染。
- 复现：Godot `--path game --script res://tests/island_y_sort_test.gd`；增加 `--headless` 只运行逻辑检查。
- 补充截图 04–06：左下林岛（0.9 倍）、四周外岛（0.85 倍）、外岛遮挡近景（1.65 倍）；继续使用同一游戏绘制逻辑，位置及相机参数保存在测试脚本中。
