# flying_garden · Godot 4.7 测试 Demo

一版可直接运行的玩法与 UI 原型，界面信息层级参考小型桌面农场游戏，但美术与代码均为本项目原创实现。2026-10-23 已接入统一的 2D 粗颗粒马赛克地形、作物、树木、角色和设施素材。

## 运行

- 使用 Godot 4.7.2 或同系列 4.7 版本打开本目录。
- 运行主场景 `main.tscn`，或按 F6/F5。

动力室已接入干净版飞轮动画：实际建筑绘制通过 `scripts/engine_room_animation.gd` 驱动轮辐，完整连接杆、原轮圈与烟雾保持原样。研究动力工程并建造动力室后自动生效，已有动力室使用同一绘制路径。主场景实时建造与动画验证：`godot --path game --script res://tests/engine_wheel_integration_test.gd`（需要图形渲染环境）。

## 操作

功能入口统一集中在最左侧 64 像素宽的纯图标单列：视角、地图、开发、科技、能源、帮助、抓钩、种植、采集、布局与存档。按钮不显示文字和悬停提示，原快捷键保留。采集为镐头、开发为锤子、布局为四格图、存档为软盘。商人到访只在工具栏下显示金币图标，悬停可查剩余时间；展开其他功能时收起，退出后恢复。

岛屿观察不再随鼠标自动弹出。上帝视角下，鼠标指向雷达范围内未连接岛屿的实际地块，按 **E** 在左侧展开详情；再次按 **E**、**Esc** 或“收起”关闭。鼠标移开后详情仍可阅读，岛屿接入、失效、离开雷达或切换视角时自动关闭。自身地块使用右键菜单，开发操作提示跟随选中地块出现，屏幕边缘自动调整位置。全局开发面板为窄侧栏；科技树、整岛布局等大界面仅在主动打开时展开。

- `T → 整岛规划`：先研究岛屿剪裁和岛屿开拓 II，再花费 300 金币、30 木材、40 石材、12 矿物解锁。`B → 整岛剪裁 / 布局预设` 打开整岛编辑图，拖动单格、框选后成片移动，单格落到占用格可交换；滚轮缩放、中键平移。核心固定，应用时须保持岛屿连通及港口处于外围。
- 三个布局预设随游戏存档保存，仅记录地块位置；增减地块后旧预设需重存。建筑、作物进度、耐久和加固随地块移动。编辑、取消和保存预设免费；每次应用消耗基础 **500 金 / 60 木 / 80 石 / 20 矿**，另按每个移动地块追加 **40 金 / 4 木 / 6 石 / 2 矿**。界面先展示总价，再确认扣费；没有变化不收费。抓钩工作或飞船出航时不能重排，与外岛重叠的布局也不能应用。
- 飓风中的烟囱烟朵会向风向偏移、横向拉散并提前消失；晴天至雷暴的普通风力下沿用原效果，建筑母版、飞轮和灯光保持原样。

专项验证：`godot --headless --path game --script res://tests/island_layout_test.gd`（60 项）；去掉 `--headless` 输出布局与应用后游戏截图。`tests/cyclone_smoke_preview.gd` 以实际建筑绘制逻辑导出 80 帧飓风/晴天对照，并逐帧校验建筑不变区。可用 `art_templates/complex_ui/preview_layout_smoke.ps1` 重现预览和 GIF/MP4。

- `F5` / 左侧“存档”：五个独立存档位。标题画面可读档，关闭窗口或从存档菜单退出会询问是否保存；覆盖和读档有单独确认。

- `WASD` / 方向键：持续施加推力；浮岛按质量产生明显惯性，松键后逐步制动。
- `空格`：紧急制动。消耗 25 E，并损失 30%（最多 8 份）未收获作物。
- `Tab` / `V`：切换上帝视角与微观视角；手动驾驶会自动回到上帝视角。
- `M`：打开天空地图；左键标记目的地，`Enter` 启动自动驾驶，`Esc` 或驾驶键接管。
- 微观视角下用鼠标中键拖拽或屏幕边缘滚动，镜头中心限制在玩家实际拥有的岛屿地块内，只显示自己的岛；滚轮检查细节。上帝视角始终容纳整座岛及树冠、屋顶，可继续缩小扩大视野；合并、剪裁与移动后自动更新取景。雷达范围外的外岛和物资不显示，天空地图用迷雾遮挡未知区域。
- `1` / `Q`：抓钩工具；鼠标左键发射，右键提前收回。
- 抓钩不是开局能力：先研究抓钩工程并建造唯一的抓钩小屋。对小岛发射后，拖至主岛附近并由工人固定；大型岛、超级岛与商店岛还需要对接科技。
- 底部直接选择“水稻”或“番茄”，再点击浮岛上的农田播种或收获；`2` / `F` 会切回当前作物。鼠标悬停只高亮地块，不再弹出种植提示。
- 水稻种子与番茄种子独立库存，开局分别 3 份和 2 份；播种只扣对应种子，收获只返还原作物的 1 份种子。采集草地/林木各获得 1 份稻种和 1 份番茄种子；商人可单独出售两种种子，管理小屋播种也不会混用。林木改用 3 木材和 1 粮食扦插。
- 每份水稻收获提供 2 金币，番茄提供 4 金币；每格固定产出 1 份作物。商人到访后可低价出售库存：水稻 1 金/份、番茄 2 金/份。
- 商人不占岛上地块。到访时在最左侧工具栏下显示紧凑交易按钮、停留倒计时和一次提示音，点击即可交易；浏览其他功能面板时收起提示；未到访时没有常驻入口或闲置面板。首次到访在开局 45 秒后，停留 75 秒，离开 210 秒后再访；浏览交易界面时倒计时继续。离开后提示和交易界面自动关闭。购买与出售分为两个页面，每种商品展示对应图标、库存、价格单位和本次交易总价；补给包展示全部内含物品。
- 商人和已对接商店岛高价出售石材 10 金/份、矿物 35 金/份、岩浆晶 90 金/份，可购买 1 或 5 份；木材包为 20 金换 8 木材。保留种子、粮食补给以及 3 矿物换 35 金的库存回收。
- `R` / 顶栏能源按钮 / 右键能源工厂：选择能源来源（水稻、番茄、矿物、岩浆晶或不选择）。来源需要对应科技；默认不选择，不会自动补能。
- 能源继续按移动、抓钩、自动驾驶等正常操作消耗。选择来源并建成能源工厂后，每 12 秒仅消耗该来源 1 份来补能，直至满能或来源耗尽；最后一份补至容量上限。满能后暂停，能量下降或来源补货后继续；绝不自动换烧其他库存，选择“不选择”立即停止补能。能源耗尽时仍可手动种植和收获，但移动、抓钩与自动驾驶会被拒绝。
- 世界没有硬边界；离出生点超过 150×150 格范围后进入云海边缘并自动减速 50%。

## 岛屿规模

玩家岛屿正式容量为 **100 格**，常规发展目标为 **81 格**，建议成长节点为 25 → 36 → 49 → 64 → 81 → 100 格（这些节点不额外锁定科技）。顶栏显示已用/上限及剩余容量提示。抓钩命中、固定开始和合并提交都会检查容量，超限时整岛拒绝接入，不销毁原岛、不截断地块；剪裁或崩落后释放容量。商店岛只打开交易，不占容量，满岛仍可交易。已消耗的抓钩发射或牵引能源不返还。

编辑器中的 `debug_player_tile_limit` 可在调试构建中显式提高至 144，默认仍为 100，发布构建始终执行 100。压力测试可直接构造超大数组以测试引擎承载能力，不代表正常游戏可以突破合岛上限。

规模配置集中在 `scripts/scale_rules.gd`。未来战斗场景总地形目标 160 格，包含玩家岛；玩家 100 格时最多再分配 60 格给战区。该预算和单位预算为待验证设计目标，尚无战斗系统实现，也不代表 60 FPS 保证。正常世界不会因为预算隐藏仍有碰撞的岛屿。

容量检查：`godot --headless --path game --script res://tests/scale_limits_test.gd`；去掉 `--headless` 可检查 HUD 并生成 `artifacts/game/island-capacity-preview.png`。

游戏采用自由建设模式，不设金币、收获次数或采集次数的通关目标。

## 原型范围

初始主岛由 25 个独立地块拼成：中央 3×3 农田，外圈草地、树木、矿石、沙地和一座储能室。开局没有引擎与抓钩，玩家必须先在岛内采集、种田和研究，再建造动力。地块单独保存坐标、地形及设施；捕获的小岛可沿主岛边缘扩张，不覆盖原有地块，质量和镜头平移范围随地形更新。运行时美术位于 [`assets/pixel_v2/`](assets/pixel_v2/)，采用 80×64 地块、小人 40 px、成熟作物 30–32 px、大树 110 px 的统一比例。

地块逻辑独立、视觉连接：直接绘制选定的原图，保留单块的外沿齿边和土石层，仅遮挡相邻格的重复内边；农田保留绿色田埂。树木使用已选定的大树 v2 原稿，作物按实际阶段范围等比显示。13 张源 PNG 均有 SHA-256 不变性检查，未经确认不修改素材。可运行 `godot --path game --script res://tests/terrain_visual_test.gd` 检查实际渲染接缝并生成近景预览。

世界按 640 px 航区确定性生成，普通浮岛密度已降低，并加入更稀有、资源更多的大型岛与超级岛。雷达科技逐级扩大地图可见距离；漂流商店岛和前期会短暂停留的流浪商人提供应急补给和作物收购。已合并的小岛在本次游戏内不会因离开航区而重生。密度参数位于 `scripts/world_layout.gd`，地块布局和绘制位于 `scripts/island_tiles.gd`。

`T` 打开独立的可视化科技树：分支连线、图标、等级进度和右侧详情共用 `development_rules.gd` 的配置。当前已接入动力、储能、能源工厂、抓钩、对接、开拓、雷达、小屋升级、林业、天气预报、剪裁、加固、回收、港口与探索飞船等分支。五个独立存档位已实现；完整教程及移动端操作仍待后续接入。

前期矿物门槛下调：动力与抓钩的初级研究各需 1 矿物，对应建筑各需 1 矿物；储能初级研究与建筑各需 1 石材；能源工厂建造需 2 石材、2 矿物。各科技的升级费用统一按基础成本 ×3^(当前等级) 计算，金币和每种材料都按 ×1、×3、×9 消耗，科技树展示的报价与实际扣除一致。例如动力工程 I/II/III 分别需要 25/75/225 金、3/9/27 木材、1/3/9 矿物。

岛上不显示常驻人物、商人或抓钩施工小人，固定进度条仍保留；商人仅通过到访提示与交易界面出现。原先预留的地块恢复为普通沙地，可正常采集、开垦、建造或剪裁。

作物基础成熟时间为 45 秒；取消规模农业及 `H/J` 全岛批量操作。研究小屋升级 I 后可建造自动化管理小屋（60 金、10 木、4 石、2 矿），每 6 秒自动收获并补种周围农田。每座小屋独立选择水稻/番茄或暂停；以自身所在格为圆心按格坐标直线距离计算半径，1/2/3 级分别覆盖 2/3/4 格，升级须先研究对应等级科技。小屋只管理农田，不采矿、不伐木、不修缮、不建造；损坏的小屋或农田暂停管理，缺少对应种子时等待补给，两座及以上正常运行的小屋覆盖同一农田时默认补种水稻，缺少稻种时等待，已有作物收获后再切换；覆盖重叠不会重复发奖。右键小屋可设置、升级和搬迁，悬停或打开菜单会显示覆盖范围。受损农田不能重新播种；碰撞会毁坏现有作物，飓风则扣除受防护减免后的生长进度，耐久耗尽才完全毁坏。`B → 修缮` 按类别收费：农田 1–3 金 + 1 木；普通地块按损伤最高需 120 金、18 木、24 石、6 矿；房屋金币为原建造价格的 35–75%（向上取整），各类材料均不超过原建造用量。`B → 农田整平` 花费 2 金将空农田恢复为普通土地，可重新开垦或建房，已有作物须先收获。受损普通地块必须先修缮再开发。

顶部为带空岛风格背景画布的紧凑单行：浅天空色天气面板、云朵纹理、苔草石质下沿与小藤叶共用一条浮岛轮廓。最左侧显示天数、时间、天气、生长增减益、灾害和持续时间；中间用图标显示地块、质量、房屋、金币、木材、石头、矿物、岩浆、能源、水稻、番茄、水稻种子和番茄种子；视角、天空地图、开发、科技、补能和帮助统一移至最左侧工具栏。两种种子使用带各自作物标记的种子袋图标，悬停可查看名称和完整库存。快捷键保持 `Tab/V`、`M`、`B`、`T`、`R`，午夜自动进入下一天。飞行场景保留雨雪、闪电与风，不再叠放天气图标或天气区域状态卡；天空地图保留区域预报。

鼠标移入树冠遮挡区域时，树木降至 26% 不透明度，移开后恢复，命中范围跟随风摆；地块点击不受树冠遮挡。树干根部对齐地块中央，树木和各阶段作物以根部固定的弯曲动画随风摇摆，飓风下增强并带阵风；烟囱间隔冒出一朵朵白色烟团，普通风力下向上漂浮、膨胀、消散并轻微横移，飓风下随风向左拉散并提前消失。储能灯与引擎转轮也有动态。岛影按实际地块轮廓生成柔边投影，合并、剪裁或崩落后自动更新。

林木保护半径 2 格内农田，天然林基础减灾 15%；空岛林业解锁种树，防护林工程 I/II/III 将减灾提升至 30%/45%/60%。多棵树只取最强保护，受损树按耐久降低保护，采走或毁坏后立即失效。保护缓解严酷天气下的生长惩罚、积雪和飓风损伤；与天气预报叠加仍至少保留 20% 灾害损伤，生长也不能恢复至正常天气水平。碰撞用双方实际占用地块判定，包围圆仅用于远处预警，凹形缺口、树冠与阴影不算碰撞体积。真实接触且法向撞击速度达到 35 才会损毁接触处地块，双方质量与速度决定连锁坍塌；低速接触只分离岛屿。

## 2026-10-26 机制修改

通关目标已删除。18:00–06:00 为夜间，作物生长在原有天气与健康系数基础上再乘 0.8；场景有星空、萤火与岩浆光，HUD 和操作面板保持正常亮度。

右键地块可加固、剪裁或回收。加固科技 5 级，每级解锁 3 次地块升级；每次耐久上限 +20，最多 400。地块费用从 2 金 + 1 石起逐次翻倍；科技费用从 10 金 + 2 石起逐级乘 3。加固地块在撞击时先损失耐久，耗尽才崩落。剪裁、回收各消耗 2 金 + 1 木；三级回收科技返还实际加固投入的 25% / 45% / 65%，各资源向下取整，基础地块仅返还 1 石头。
