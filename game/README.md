# flying_garden · Godot 4.7 测试 Demo

一版可直接运行的玩法与 UI 原型，界面信息层级参考小型桌面农场游戏，但美术与代码均为本项目原创实现。

## 运行

- 使用 Godot 4.7.2 或同系列 4.7 版本打开本目录。
- 运行主场景 `main.tscn`，或按 F6/F5。

## 操作

- `WASD` / 方向键：持续施加推力；浮岛按质量产生明显惯性，松键后逐步制动。
- `空格`：紧急制动。消耗 25 E，并损失 30%（最多 8 份）未收获作物。
- `Tab` / `V`：切换上帝视角与聚焦视角；手动驾驶会自动回到上帝视角。
- `M`：打开天空地图；左键标记目的地，`Enter` 启动自动驾驶，`Esc` 或驾驶键接管。
- 聚焦视角下用鼠标中键拖拽或屏幕边缘滚动；滚轮调整当前视角缩放。
- `1` / `Q`：抓钩工具；鼠标左键发射，右键提前收回。
- 对小岛发射抓钩：拖至主岛附近后，工人约用 2 秒固定；按空闲网格接入，保留原地形。开局右上方有一座可直接抓取的林地岛。
- `2` / `F`：种植工具；点击浮岛上的 3×3 农田播种或收获。
- 农田格使用独立模块视觉：悬停显示就地状态卡，点击后固定该格详情；空闲、生长、成熟分别用播种提示、进度条和金色标记区分。
- `R`：优先消耗能源作物补充 35 E，否则消耗水稻补充 15 E。
- 能源不会自行恢复；能源耗尽时仍可种植和收获，但移动、抓钩与自动驾驶会被拒绝。
- 世界没有硬边界；离出生点超过 150×150 格范围后进入云海边缘并自动减速 50%。

## 本版目标

- 金币达到 200。
- 收获作物 2 次。
- 使用抓钩回收 3 件漂浮物。

## 原型范围

初始主岛由 25 个独立地块拼成：中央 3×3 农田，外圈草地、树木、矿石、沙地和三种设施。地块单独保存坐标、地形及设施；捕获的小岛可沿主岛边缘扩张，不覆盖原有地块，质量和镜头平移范围随地形更新。手动选择拼接位置、地块编辑及完整建造系统后续补充。

世界按 640 px 航区确定性生成，周边加载林地岛、矿石岛、沙地岛、草甸岛及物资；离开出生点仍保持密度。天空地图显示地块轮廓和物资位置。已合并的小岛在本次游戏内不会因离开航区而重生。密度参数位于 `scripts/world_layout.gd`，地块布局和绘制位于 `scripts/island_tiles.gd`。

当前自动驾驶相关科技在机制测试版中默认解锁；正式科技购买、存档、完整教程及移动端操作由后续机制接入。

自动检查：`godot --headless --path game --script res://tests/smoke_test.gd` 和 `godot --headless --path game --script res://tests/island_test.gd`（从仓库根目录运行）。

原创像素 UI 图标位于 `assets/ui/farm_ui_icons.png`。详细来源见 `THIRD_PARTY_NOTICES.md`；农田地块 UI 规范见 `../docs/mechanics/12-农田地块UI.md`。
