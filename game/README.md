# flying_garden · Godot 4.7 测试 Demo

一版可直接运行的玩法与 UI 原型，界面信息层级参考小型桌面农场游戏，但美术与代码均为本项目原创实现。2026-10-23 已接入统一的 2D 粗颗粒马赛克地形、作物、树木、角色和设施素材。

## 运行

- 使用 Godot 4.7.2 或同系列 4.7 版本打开本目录。
- 运行主场景 `main.tscn`，或按 F6/F5。

## 操作

- `WASD` / 方向键：持续施加推力；浮岛按质量产生明显惯性，松键后逐步制动。
- `空格`：紧急制动。消耗 25 E，并损失 30%（最多 8 份）未收获作物。
- `Tab` / `V`：切换上帝视角与聚焦视角；手动驾驶会自动回到上帝视角。
- `M`：打开天空地图；左键标记目的地，`Enter` 启动自动驾驶，`Esc` 或驾驶键接管。
- 聚焦视角下用鼠标中键拖拽或屏幕边缘滚动；滚轮调整当前视角缩放。
- `1` / `Q`：抓钩工具；鼠标左键发射，右键提前收回。
- 抓钩不是开局能力：先研究抓钩工程并建造唯一的抓钩小屋。对小岛发射后，拖至主岛附近并由工人固定；大型岛、超级岛与商店岛还需要对接科技。
- 底部直接选择“水稻”或“番茄”，再点击浮岛上的农田播种或收获；`2` / `F` 会切回当前作物。鼠标悬停只高亮地块，不再弹出种植提示。
- 每株作物基础只提供 2 金币，主要价值仍是食物与能源原料；规模农业可提高单格产量。
- `R`：让已建成的能源工厂立即处理一次燃料。作物、矿物和岩浆晶均需要对应科技，转化率随科技提高。
- 能源不会自行恢复；能源工厂每 12 秒可自动处理一次燃料。能源耗尽时仍可种植和收获，但移动、抓钩与自动驾驶会被拒绝。
- 世界没有硬边界；离出生点超过 150×150 格范围后进入云海边缘并自动减速 50%。

## 本版目标

- 金币达到 200。
- 收获作物 2 次。
- 采集 3 格岛内资源。

## 原型范围

初始主岛由 25 个独立地块拼成：中央 3×3 农田，外圈草地、树木、矿石、沙地和一座储能室。开局没有引擎与抓钩，玩家必须先在岛内采集、种田和研究，再建造动力。地块单独保存坐标、地形及设施；捕获的小岛可沿主岛边缘扩张，不覆盖原有地块，质量和镜头平移范围随地形更新。运行时美术位于 [`assets/pixel_v2/`](assets/pixel_v2/)，采用 80×64 地块、小人 40 px、成熟作物 30–32 px、大树 110 px 的统一比例。

地块逻辑独立、视觉连接：直接绘制选定的原图，保留单块的外沿齿边和土石层，仅遮挡相邻格的重复内边；农田保留绿色田埂。树木使用已选定的大树 v2 原稿，作物按实际阶段范围等比显示。13 张源 PNG 均有 SHA-256 不变性检查，未经确认不修改素材。可运行 `godot --path game --script res://tests/terrain_visual_test.gd` 检查实际渲染接缝并生成近景预览。

世界按 640 px 航区确定性生成，普通浮岛密度已降低，并加入更稀有、资源更多的大型岛与超级岛。雷达科技逐级扩大地图可见距离；漂流商店岛和前期会短暂停留的流浪商人提供应急交易，其中矿物为 35 金币购买 1 份的高价保底来源。已合并的小岛在本次游戏内不会因离开航区而重生。密度参数位于 `scripts/world_layout.gd`，地块布局和绘制位于 `scripts/island_tiles.gd`。

`T` 打开独立的可视化科技树：分支连线、图标、等级进度和右侧详情共用 `development_rules.gd` 的配置。当前已接入动力、储能、能源工厂、抓钩、对接、开拓、雷达、农业自动化、林业、天气预报与剪裁等分支。存档、完整教程及移动端操作仍待后续机制接入。

作物基础成熟时间为 45 秒；规模农业提高单格产量，农务自动化才会开放 `H/J` 批量操作。受损农田不能播种且现有作物会损失。天气新增雪天和飓风；天气预报可以缓解灾害但不会完全免疫。碰撞会直接崩落撞击位置的地块，双方质量与速度会决定是否发生连锁坍塌。

自动检查：`godot --headless --path game --script res://tests/smoke_test.gd`、`godot --headless --path game --script res://tests/island_test.gd` 和 `godot --headless --path game --script res://tests/development_test.gd`（从仓库根目录运行）。

原创像素 UI 图标位于 `assets/ui/farm_ui_icons.png`，统一场景素材位于 [`assets/pixel_v2/`](assets/pixel_v2/)。详细来源见 `THIRD_PARTY_NOTICES.md`；农田地块 UI 规范见 `../docs/mechanics/12-农田地块UI.md`。
