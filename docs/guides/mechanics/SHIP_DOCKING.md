# 探索船对接、耐久、扩容和超载

> 路径说明：本文的 `scripts/`、`tests/`、`assets/` 等代码路径以项目 `game/` 目录为根；命令从项目根目录运行。

港口派遣后，探索船自动寻找探索等级允许的矿岛，并在靠近真实地块轮廓时减速。接触后停在岛外，船旁出现「对接并采集」按钮；未点击前不采矿。左侧飞船视角按钮可跟随查看。点击后按高效采集科技决定的间隔采集，矿岛耗尽、货满或需要保留返程能源时返航，只能在完好的港口泊位卸货、充能。

碰撞检测使用80×64船体与岛上实际占用地块，检测整段移动路径，避免高速穿透；空白凹口、树冠和阴影不算碰撞。撞击按朝向碰撞面的速度计算，低于35 px/s无伤害；否则扣除 `clamp(20 + (速度 − 35) × 0.35, 20, 60)` 耐久。满血100，一次撞击至多60伤害，撞后停止移动；耐久归零时船与在舱货物损失，可以按原价重建。

在完好港口停泊时，可通过飞船管理修理。每点缺失耐久收10金币，木材和矿物各收「缺失耐久÷10，向上取整」。修理不会补电；毁坏后重建也是空舱、零电量。

## 飞船扩容

入口：`T → 港口与探索 → 飞船扩容`，前置为探索飞船I。

| 1 | 400 |
| 2 | 640 |
| 3 | 1000 |
| 4 | 1500 |
| 5 | 2200 |
| 6 | 3200 |
| 7 | 4500 |
| 8 | 6000 |
| 9 | 8000 |
| 10 | 10000 |

一级1000金币、20木材、10矿物，此后每级费用乘3。十级为19,683,000金币、393,660木材、196,830矿物。详情卡显示当前和下一级容量，十级后不可继续研究。

按用户确认，扩容同步改善装载能效：每矿点耗电为 `12 × 24 / 容量`；速度为 `150 / (1 + 2 × 当前载荷 / 容量)`。空舱150、半舱75、满舱50 px/s，拖拽阻力也使用装满比例。电池容量仍500；每矿点原产出不变，实际每趟还受矿岛剩余资源、航程和电量限制。三种货舱外观按当前容量判断空载／未满／满载。

## 下一批资源装不下

采矿暂停在消耗矿点之前，提示剩余空间以及将丢弃的资源种类、数量，并提供两个选择：

- 继续采集：只装入剩余空间能容纳的资源，完整消耗这个矿点及一次采矿电量；超出部分永久丢弃，显示再次警告，满载后返航。
- 停止采集并返航：当前货物、当前矿点和电量均不因这次待确认采集而改变。

保留资源按现有矿点产出顺序装载；确认前会显示具体丢弃清单。例如普通矿点产4石材＋4矿物，仅剩2格时保留2石材，提示丢弃2石材＋4矿物。等待期间不继续自动开采，保存/读档不会代替用户确认。飞船管理中也可查看丢弃警告并确认，或召回飞船。

存档保存耐久、扩容等级、接触/采矿/超载等待状态与相对岛屿的对接位置。旧档缺失字段时使用满血、基础240格；旧的直接采矿状态会重新靠岛并等待对接。无效血量、无效科技等级、超过当前容量的货物、非有限计时或坐标均被拒绝。
