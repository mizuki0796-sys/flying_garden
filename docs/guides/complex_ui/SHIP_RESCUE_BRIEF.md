# 小飞船视角、雷达与救援

- 用户要求：左侧工具栏切换小飞船视角；天空雷达显示飞船；耗能停航后可用抓钩拉回，只能与港口对接，或付出高额费用直接回归。
- 范围：复用现有按钮、飞船三态素材、相机、地图及抓钩，不重新生成图或新增船体组件。主岛、港口、船体及既有尾气不重画。
- 视角按钮：点击跟随小飞船，再次点击返回主岛；未造船禁用。地图显示实时货舱缩略图、状态及电量，点击可打开管理。
- 无电：取消旧 15% 速度漂航，原地等待救援，保留货物。抓钩可命中失去动力的飞船，拖拽耗主岛能量并只拉至完好港口外侧泊位；不新增地块。
- 付费救援：按用户最新修正降至原方案十分之一，5,000 金币基础价，加距离每 80px（向上取整）100 金币。操作确认时重新计算并显示费用；无港口、破损港口、余额不足不能扣款或传送；不补满飞船能源。
- 持久化：兼容旧存档；新增拖拽身份字段可选，保存/恢复货物、位置和救援状态。视角偏好不写入存档。
- 验证：相机跟随/返回、地图图标及悬停、耗能停车、真实抓钩命中/回港/中断、付费失败无扣款及成功单次扣款、存档往返、现有回归测试和实际截图。
- 实现：main.gd 工具栏/相机/抓钩命中/雷达；exploration_ship.gd 失去动力、拖拽与付费救援；navigation_view.gd 雷达悬停/点击；save_slots.gd 校验可选 towed 字段并重置视角跟随。
- 回归结果：ship_rescue_test 无图形 30 项、实际图形 34 项（含四张截图），均 0 失败；ship_states_test 83 项、navigation_test 29 项、mechanics_update_test 142 项通过，smoke_test 通过。
- 复现：Godot `--path game --script res://tests/ship_rescue_test.gd --rendering-method gl_compatibility`；输出 `artifacts/game/ship-rescue/`。没有生成或修改任何船体/港口位图。
- 未验证导出包与长期性能；未新增视频。视角切换只改变相机，方向键仍驾驶主岛。
