# 探索船接触对接与船体耐久

- 用户要求：真实碰撞体接触、慢速靠岛弹出船旁对接按钮；确认对接后限量采矿；高速撞击损失大量血量，归零毁坏。
- 本次范围：复用现有方形船体、三种货舱图和灰白尾气，新增耐久条、船旁对接按钮、超载确认卡、管理面板维修项及飞船扩容科技节点；不改船体素材和其他建筑。
- 已确认规则：自动减速靠岛，安全接触速度低于35 px/s；耐久100，高速碰撞20–60伤害，接触停下避免持续重复扣血。基础每趟24份，满载或缺电返航；毁坏损失船和在舱货物，可以重新建造。
- 扩容：十级，容量从24依次提升至40、64、100、150、220、320、450、600、800、1000。用户确认同步提升装载能效，速度和拖拽重量按装满比例计算，单次采矿耗电为12×24/当前容量，电池仍500。
- 超载：下一矿点产出超出剩余空间时暂停，不消耗矿点和电量。明确展示将丢弃的资源类型及数量；确认后只保留可装入部分并再次警告丢弃，取消则携当前货物返航。等待状态保存后仍需确认。
- 维修：仅完好港口停泊时，按缺失血量每点10金币计费，并按每10血向上取整消耗1木材和1矿物。
- 实现：实际80×64船体与外岛占用地块进行连续碰撞检测，不使用包围圆作为接触判据。复用游戏按钮和血量绘制风格。
- 保存：新增耐久、接触/超载状态、对接偏移及扩容等级；旧档缺少字段时补满血和基础24格，旧采矿状态重新靠岛确认。
- 验证：慢速接触不采矿、按钮确认、掠过/高速穿透、低血毁坏和重建、1000份采集返航、修理扣费、超载确认/取消/读档、实际绘制预览。
