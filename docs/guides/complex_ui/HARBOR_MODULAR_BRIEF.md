# 工业模块港口设计稿 v2

- 最新要求：加入一点重工业风格；单块能拼接，大型及超大型飞船通过拼接大港口停泊。
- 母版：`artifacts/game/harbor-concept-v1/harbor-side-berth-v1.png`；作为结构参考，允许重绘整个港口。
- 允许变化：港口材质改为钢梁、铆接钢板与少量木质嵌板；局部黄黑警示条；缩短入口，调整上下端为齐平拼接接口。
- 靠泊关系：飞船停在码头右侧外部；甲板通行与装卸，不做顶部停机坪。
- 拼接方向：当前采用上下直线扩建；单块服务小船，多块形成连续外侧泊位，供大型及超大型船使用。暂不扩展转角、四向接口或新玩法规则。
- 接口：上下同宽、同高度、横截面对应；接口无围栏与挡路立柱。系泊桩及护舷仅放在外侧且避开接缝。
- 规范：遵循项目 STYLE_GUIDE 和 COMPLEX_UI_ANIMATION_GUIDE，近正俯视正交、粗像素、左上光源、每材质最多三档主明度。
- 输出：一张概念图，包括单模块和三个相同模块连续拼接示意；不绘制船只。
- 保持：既有游戏代码、飞船、场景、玩法和特效不变；无新增灯、烟、动画与机械运行状态。
- 验证边界：生成图用于设计确认；接口像素、逻辑格尺寸与实际游戏拼接需在接入阶段校准，不将生成的拼接示意当成运行时验证。
