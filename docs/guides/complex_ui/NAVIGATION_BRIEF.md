# 天空地图与手动航向

- 用户最新要求：直接移除上帝视角；天空地图支持滚轮缩放。
- 后续要求：现实玩家视角用滚轮拉近观察细节，拉远最多恢复默认视野。默认范围按现有 0.75 比例与本岛完整取景比例的较小值确定，近景上限复用 2.0；天空地图比例独立。只调整镜头，不改素材、设施或动画。
- 修改范围：删除上帝视角、工具栏入口、Tab/V 绑定及云层过渡；地图的比例、输入、绘制、标记和悬停坐标统一调整。
- 母版：复用现有 main.gd 天空地图与 UI 色板；无新位图、动画或补绘。
- 保持：现实场景素材、建筑特效、地图暂停、WASD 平移、点击标记、0.55 秒悬停详情和手动驾驶。旧存档中的自动导航继续禁用。
- 参数：地图默认比例 0.16，范围 0.06–0.8；滚轮每格乘/除 1.2，围绕鼠标缩放。地图中心沿用已加载雷达范围限制，触及边界时优先保持边界。
- 绘制：岛屿、天气、网格、雷达迷雾与目的地连线统一使用当前比例；地图外滚轮不影响地图或现实镜头。
- 预览与验证：tests/navigation_test.gd 调用实际游戏绘制，输出 artifacts/game/navigation/ 中默认、放大、缩小与悬停截图。旧云层预览仅为历史产物，不再接入游戏。
- 验证结果：29 项导航检查通过无头与 OpenGL 实际运行，包含滚轮输入、缩放上下限、鼠标锚点、缩放后标记/悬停、退出与旧存档；left_ui 13、mechanics 142 和 smoke 回归通过。
