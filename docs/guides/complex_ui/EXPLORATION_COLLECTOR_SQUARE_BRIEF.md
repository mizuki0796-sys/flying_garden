# 方块收集飞船 v2

- 最新要求：降低科技感，结合浮岛风格，改成方块型收集飞船；整体比单块地块小一点。
- 允许修改：飞船整体轮廓与材质重绘；细长金属机体改为接近正方形的木质箱型飞行驳船。
- 保留用途：船头收集斗、显眼开放货舱和矿石，体现探险采集运输；飞船在港口旁靠泊。
- 结构：紧贴船头的短宽铲斗；中央方形货舱；后角小型木质舵室；左右小型木叶螺旋桨，避免大风扇及长支臂破坏方块外形。
- 材质：蜂蜜色木梁与木板为主，深绿铁箍、少量铜接件；弱化现代装甲、玻璃驾驶舱、涡扇与黄黑工业条纹。
- 参考：v1 飞船只参考采集用途；`game/assets/pixel_v2/facilities/engine_room_v2.png` 参考浮岛设施的色彩和粗像素。
- 尺寸约束：单块地块为 80×64；飞船完整可见外轮廓（含船头铲斗、两侧螺旋桨及全部附件）限制在 72×56 逻辑像素以内。按去除透明留白后的主体边界等比适配，不将船身单独按此尺寸后再向外添加附件，不为填满边框拉伸图像。
- 规范：近正俯视正交、粗颗粒形态、左上光源、有限色板、每材质最多三档明度。方块外观与地块匹配，运行时尺寸以上述外轮廓约束为准。
- 范围：一张独立透明底静态概念图；不新增灯、烟雾、动画、运行状态或玩法。
- 保持：现有港口、既有素材、游戏代码、存档均不变。
- 验证：目视检查方块比例、低科技浮岛风格和收集可读性；尚未校准运行时像素、动画及靠泊尺寸。
