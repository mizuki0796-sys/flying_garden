# 12 · 独立农田地块 UI

单格农田的状态表达与信息层级已经接入；2026-10-23 机制轮次同时调整了成长时间、科技产量、灾害损伤和播种限制。

## 设计目标

- 玩家不看右侧说明，也能在半秒内分清空闲、生长、成熟三种状态。
- 5×5 浮岛仍是一块整体，但中央 3×3 农田必须显得是 9 个独立、可点击的经营模块。
- 信息按“地块本体 → 就地浮层 → 右侧档案”逐层展开，避免把所有数字长期压在地图上。
- 颜色只用于加强，不作为唯一提示；成熟地块同时使用金色脉冲和感叹标记。

## 三层信息结构

1. **地块本体**：深色立边、独立圆角边框、作物色签和土垄，负责说明“这里能操作”。
2. **就地浮层**：悬停或选中时显示作物、状态、主要动作及最关键收益。
3. **右侧地块档案**：显示坐标、精确进度、预计成熟时间、天气效率、产能值和耐久。

## 状态规范

| 状态 | 地块表现 | 就地信息 | 主要动作 |
|---|---|---|---|
| 空闲 | 土垄、播种孔；种植工具悬停时出现加号 | 播种消耗与收获价值 | 左键播种 |
| 生长 | 作物阶段贴图、地块底部绿色进度条 | 百分比、预计剩余秒数 | 查看进度 |
| 成熟 | 完整作物贴图、金色脉冲感叹标记 | 收获收益与种子返还 | 左键收获 |
| 受损 | 裂痕与耐久条；现有作物直接损失 | 右侧档案显示耐久、禁种和修缮成本 | `B` → 修缮 |

水稻使用米黄色签，番茄使用珊瑚红色签；即使地块为空，也能预知该格当前绑定的作物类型。

## 交互规则

- 悬停立即显示就地浮层，不需要先点击。
- 点击播种、查看或收获的同时选中该格；鼠标移开后，种植工具下仍保留浮层和右侧档案。
- 切换到抓钩或开发工具时取消农田选中，避免旧信息干扰其他操作。
- 底部种植按钮显示成熟待收数量，例如 `种植 [2]`。

## 参考取舍

- [Farm Keeper](https://store.steampowered.com/app/2458940/Farm_Keeper/)：借鉴密集网格里每格仍有明确边界和状态的原则。
- [Garden Galaxy](https://store.steampowered.com/app/1970460/Garden_Galaxy/)：借鉴独立模块拼成整体花园的空间感。
- [Rusty's Retirement](https://store.steampowered.com/app/2666510/Rustys_Retirement/)：借鉴作物阶段在缩小画面下仍可辨识的原则。

只参考信息层级与可读性，边框、色彩、标记和交互均使用本项目现有素材与原创实现。

## 验收结果

- 默认 1152×648 画面中，9 格农田边界清晰，没有改变点击区域。
- 空闲、生长、成熟状态均可仅凭地块视觉判断。
- 就地浮层不会在天空地图、开发弹窗或非种植工具的固定选中状态下残留。
- 冒烟测试覆盖地块选中、档案内容和切换工具后的收起行为。
