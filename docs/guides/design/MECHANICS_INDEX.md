# flying_garden 游戏机制目录

这份目录是后续逐项修改的唯一索引。一次只处理一个编号；该项通过试玩与验收后，再进入下一项。

历史机制可在 [2026-10-26 机制修改表](../../../tools/mechanics-planner/archive/mechanics/现有机制修改表-2026-10-26.html) 中查看和填写；最新登岛方案使用 [登岛作战设计审阅表](登岛作战设计审阅表-2026-11-04.html)。填写后请导出保存。本页保留早期机制梳理记录，状态不代表当前代码审计。

## 状态说明

- `可运行`：已有实现并通过基础自动测试。
- `原型`：已有演示功能，但手感、规则或表现仍需确定。
- `未实现`：只有设计目标，尚无游戏代码。
- `后置`：依赖前面的核心机制，不应提前精修。

## 当前 Demo 已有内容

- 主岛由 5×5 独立地块组成，中央 3×3 农田、外圈混合地形及初始储能室；开局没有引擎和抓钩。
- 抓回周边小岛后，工人固定并按空闲网格接入；保留原有地块和设施，质量与镜头可平移范围随扩张更新。
- 按航区生成较稀疏的普通岛、稀有大型岛、超级岛和商店岛；雷达科技决定地图可见距离。
- 浮岛按质量、推力和线性阻力运动，`WASD` / 方向键持续施加推力；松键会逐步制动。
- 世界没有硬边界；镜头无限跟随，离出生点超过 150×150 格范围后以云海提示并减速。
- `Tab` / `V` 切换上帝与聚焦视角；手动驾驶自动切回上帝视角，聚焦视角使用中键或屏幕边缘平移。
- `M` 打开天空地图，左键标记目的地，`Enter` 自动驾驶，`Esc` 或驾驶键接管。
- 移动、抓钩、急停和自动驾驶消耗能源；作物、矿物和岩浆晶必须通过已建造的能源工厂转化。
- 抓钩支持科技解锁、唯一建筑、射程/能耗升级、负重拖拽和大型岛对接门槛。
- 空格急停会消耗能源、损失未收获作物，并触发短暂混乱和屏震。
- 障碍进入预警半径后显示方向提示；自动驾驶会绕行或停车。
- 3×3 农田支持播种、生长、成熟和收获；规模农业提高产量，批量农务与林木种植由科技解锁。
- 晴、阴、雨、雷暴、雪和飓风区域会移动并影响作物；灾害可损坏农田，天气预报只能部分缓解。
- 撞击会直接崩落地块；速度、双方质量和质量差决定连锁破坏范围。
- HUD 包含可隐藏的左上角按键指南；科技使用带图标、连线、进度条和详情栏的独立界面。
- 漂流商店岛和限时停留的流浪商人提供资源交易。
- 自动测试覆盖 UI 初始化、种植、成熟、收获、抓钩、移动和能源消耗。
- 地块测试覆盖完整抓取扩张、地块连通与不重叠、质量更新、地图密度、跨航区负载引用和合并状态保留。

## 单项修改流程

1. 确认该机制想带给玩家的体验。
2. 写清输入、规则、数值、反馈和失败情况。
3. 只修改与该编号有关的代码和界面。
4. 运行自动测试并生成一张实机预览。
5. 试玩确认后，在本目录中记录最终规则并标记为 `可运行`。
