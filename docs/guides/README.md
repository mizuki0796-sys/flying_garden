## 归档约定

- `complex_ui/`：任务单、提示词模板、案例和验收记录。绘制代码与导出脚本在 `game/art_templates/complex_ui/`；案例中的同名脚本从该目录查找。
- `mechanics/`：游戏机制说明与历史修改记录。文中 `scripts/`、`tests/` 等路径以 `game/` 为根。
- `design/`：设计提案与可填写审阅表。表格上的“已明确”是需求状态，不代表已经实现。
- 历史任务单保留原内容，不把旧版本效果或数值自动当成当前要求；用户最新确认优先。
- 根目录 `AGENTS.md` 保留自动发现入口；根目录和游戏 `README.md` 保留启动入口。授权文件、素材随包说明与候选清单继续随原资源保存。
- HTML 意见填写后点击“保存已填写 HTML”，将意见写进下载文件；浏览器草稿不等于已经保存到磁盘。
