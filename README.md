# flying_garden

`flying_garden` 是一个使用 Godot 4.7 制作的空岛农场游戏项目。

## 打开项目

- 使用 Godot 4.7 打开 [`game/project.godot`](game/project.godot)。
- 运行和测试说明见 [`game/README.md`](game/README.md)。
- 制作规范、机制说明、设计审阅表统一见 [指导文档目录](docs/guides/README.md)。
- 第三方素材授权见 [`game/THIRD_PARTY_NOTICES.md`](game/THIRD_PARTY_NOTICES.md)。

## 仓库范围

仓库跟踪可运行的游戏工程和 `docs/guides/` 指导文档。素材候选库、其余设计草稿、辅助工具、生成物和本地运行时均保留在本地，不纳入版本控制。
